Entry for a make.fun one-line competition: a warning label for a time machine, written by `main.ts` to `entry.txt`. The label is 117 characters, built at runtime from a setup and a punchline, and the program refuses to write anything outside the 1–120 character gate.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
